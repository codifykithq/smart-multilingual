# Smart Multilingual

A powerful WordPress multilingual toolkit with RTL support, language routing, and compatibility with popular WordPress builders and plugins.

## Features

- Multi-language URL routing
- RTL/LTR automatic support
- Custom language management
- Elementor compatibility
- WooCommerce compatibility
- Theme compatibility layer
- Custom post type and taxonomy support
- Front-end language switcher
- Performance-focused architecture

## Supported Languages

- English
- Persian (RTL)
- Turkish
- Arabic
- German

## Developer Features

Built with:

- PHP
- JavaScript
- WordPress Hooks
- WordPress APIs
- AJAX
- REST API
- Custom Plugin Architecture

## Installation

1. Upload the plugin folder to:

`/wp-content/plugins/`

2. Activate the plugin from WordPress Dashboard.

3. Configure languages from plugin settings.
